Working principle

Dense information should still feel calm.

Signal / Stacktrace design system / September 2026

Built for strong opinions
and quiet confidence.

Signal is Stacktrace's interface system for technical conversation. It combines the density of developer tools with the warmth and pacing of an independent publication.

01 Precise, not sterile

Structure information rigorously, then soften it with warm surfaces and generous rhythm.

02 Dense, not crowded

Use scale, rules, and mono metadata to create hierarchy before adding containers.

03 Technical, still human

Interface copy can be concise and useful without losing wit or personality.

Layout and responsive behavior

The feed is the invariant. Supporting regions compress and disappear as space becomes scarce, while the reading column remains stable and legible.

Four responsive states

Breakpoints follow content pressure. Each state removes or relocates a region only when it can no longer perform well.

Rule 01Protect the reading measure.

Do not squeeze the feed to preserve secondary information. Remove the rail first.

Rule 02Relocate before removing.

Primary navigation moves to the mobile dock; creation remains prominent at every size.

Rule 03Reduce chrome, not capability.

Labels and supporting decoration may disappear, but reactions, sharing, and profiles remain available.
