# Packet

- A TUI app built using latest versions of bubble tea stack
- Keyboard based navigation
- Postman compliant imports
- Left shows the collections, Body on the right (bigger)
- A toggle between body and response (split, request body only, request response only)
- Auto cookie
- JWT auth (take jwt option but also calc jwt from secret and algo)
- Collections panel is scrollable show large amount of collection don't break the view
- Quick search for request
