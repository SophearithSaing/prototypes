Development

From brief to binary.

The project began as eleven product requirements and an otherwise empty directory. Development moved from data boundaries outward: define requests, make transport correct, then build the interface around those guarantees.

Establish the core

A small domain package defines collections, requests, headers, body modes, authentication, and responses. UI concerns never leak into transport types.

model first

Translate Postman

V2.0 and v2.1 collections are decoded, nested folders become paths, inherited bearer auth is retained, and collection variables are expanded.

boundary work

Shape interaction

Focus states, modals, view modes, and asynchronous commands form one explicit Bubble Tea model. Every action remains reachable from the keyboard.

state machine

Harden the edges

Long collection scrolling, narrow terminal stacking, multipart paths, response limits, cookie behavior, JWT errors, race tests, and vet complete the pass.

verify last

How it works

One event loop, clear boundaries.

Bubble Tea owns interaction state. The packet package owns protocol behavior. Slow work crosses the boundary through commands and returns as messages, keeping rendering deterministic.

03 / TRANSPORT

Build HTTP

Body mode, headers, JWT, timeout, and cookies are applied.

Render

The viewport resets to the top and displays the result.

The runtime model

The TUI stores collections and lightweight references into them. Search rebuilds only the visible reference list, so the request data remains stable and edits are not duplicated. Before selection or transport changes, URL and body widgets synchronize into the active request.

The shared packet.Client owns one standard-library cookie jar. That makes cookie behavior automatic across every request in the process without inventing a second session abstraction.

Postman files can enter at startup or through an import modal. Both routes use the same parser, preserving one import contract and one set of tests.

Decision records

Constraints became structure.

The implementation favors explicit, standard-library behavior over additional frameworks. Each choice narrows the number of states the application can enter.

ADR 001ACCEPTED

Keep protocol code outside the TUI

Imports, signing, and HTTP execution are independently testable. Bubble Tea receives plain messages instead of knowing transport details.

ADR 002ACCEPTED

Flatten folders, preserve paths

Nested Postman folders become names such as Users / Create. A flat reference list makes quick search and scrolling simple without losing context.

ADR 003ACCEPTED

Make body modes explicit

Raw, URL-encoded, GraphQL, multipart, and file bodies retain their transport semantics. The client chooses encoding and content type at send time.

ADR 004ACCEPTED

Use standard crypto primitives

JWT HMAC signing uses crypto/hmac, SHA-2, JSON, and base64url. Supporting three understood algorithms is safer than a broad opaque dependency.

ADR 005ACCEPTED

Session-local by design

Cookies and edits live for one run. No persistence format, secret storage policy, or migration layer is introduced before the product requires it.

ADR 006ACCEPTED

Bound every response

The reader stops after 10 MiB plus one byte. That extra byte detects truncation while keeping a surprising endpoint from consuming unbounded memory.

Source notes

The important paths.

These excerpts are condensed from the working implementation. They show the boundaries where interface events become protocol operations.

01 / ASYNC UPDATE

Network work returns as data

send synchronizes the widgets, copies the request, marks the interface busy, and returns a command. The event loop never blocks on HTTP.

internal/tui/model.go 
func (m Model) send() (tea.Model, tea.Cmd) {
    if m.loading {
        return m, nil
    }
    m.syncCurrent()
    request := m.currentRequestPointer()
    if request == nil {
        return m, nil
    }

    copy := *request
    m.loading = true
    m.status = "Sending " + copy.Method + "..."

    return m, func() tea.Msg {
        response, err := m.client.Do(copy)
        return responseMsg{response: response, err: err}
    }
}
02 / HTTP SESSION

Cookies are a client property

A single cookie jar sits on the shared HTTP client. Authentication and inferred content type are applied only after user headers, so explicit input wins where appropriate.

internal/packet/client.go 
func NewClient() *Client {
    jar, _ := cookiejar.New(nil)
    return &Client{http: &http.Client{
        Jar: jar, Timeout: 30 * time.Second,
    }}
}

func (c *Client) Do(in Request) (Response, error) {
    bodyReader, contentType, err := requestBody(in)
    if err != nil {
        return Response{}, err
    }

    req, err := http.NewRequest(
        strings.ToUpper(in.Method),
        strings.TrimSpace(in.URL),
        bodyReader,
    )
    // Headers, inferred content type, and bearer auth follow.
    res, err := c.http.Do(req)
    // The response is normalized before returning to the TUI.
}
03 / IMPORT

Recursion removes UI complexity

The importer walks arbitrary folder depth and emits request paths. Folder-level authentication flows downward unless a request overrides it.

internal/packet/postman.go 
func walkPostmanItems(
    items []postmanItem,
    prefix string,
    inheritedAuth *postmanAuth,
    variables map[string]string,
    output *[]Request,
) {
    for _, item := range items {
        name := item.Name
        if prefix != "" {
            name = prefix + " / " + item.Name
        }
        auth := inheritedAuth
        if item.Auth != nil {
            auth = item.Auth
        }
        if len(item.Items) > 0 {
            walkPostmanItems(item.Items, name, auth, variables, output)
            continue
        }
        request, err := decodePostmanRequest(item.Request, name, auth, variables)
        if err == nil {
            *output = append(*output, request)
        }
    }
}
04 / JWT

Signing is deliberately narrow

Claims must parse as JSON. The selected HMAC algorithm chooses a standard hash constructor, then header and payload are encoded without padding before signing.

internal/packet/jwt.go 
headerJSON, _ := json.Marshal(map[string]string{
    "alg": algorithm,
    "typ": "JWT",
})
encode := base64.RawURLEncoding.EncodeToString
unsigned := encode(headerJSON) + "." + encode(payloadJSON)

mac := hmac.New(newHash, []byte(a.Secret))
_, _ = mac.Write([]byte(unsigned))

return unsigned + "." + encode(mac.Sum(nil)), nil
