# Changelog

All notable changes to Scratchpad are documented in this file.

## 0.1.0 - 2026-08-22

### Added

- Multiple reorderable text tabs with wraparound keyboard navigation.
- Debounced per-tab auto-save and full session restoration.
- Manual Save and Save As through asynchronous GTK file dialogs.
- Safe tab removal confirmation and shutdown-time draft flushing.
- Native GTK light and dark theme support.
- Embedded JetBrains Mono Regular editor font with private app-only loading.
- Linux desktop entry, application icon, and Makefile installation target.
- Sharpened 16–256 pixel icon layers for GTK, Windows taskbar, and Alt+Tab use.
- Windows GUI-subsystem build with version metadata, application icon,
  per-monitor DPI support, and long-path awareness.
- Self-contained MSYS2 UCRT64 portable Windows packaging and CI artifact build.
